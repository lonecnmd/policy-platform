# 数字深圳项目管理政策分析平台

这是一个用于梳理、检索和分享“数字深圳项目管理政策”资料的静态网页原型。页面按投资管理、预算管理、采购管理和资产管理四个维度组织政策文件，并提供政策摘要、结构化标签、候选任务、实施流程和附件下载。

## 内容范围

平台按照四个项目管理维度、三级政策层级组织政策：

- 投资管理
- 预算管理
- 采购管理
- 资产管理

政策层级包括国家、广东省、深圳市，并保留北京、上海 2 条对标城市政策。当前版本依据 `20260819政策清单` 文件体系生成 126 条去重后的政策记录：两个政策清单目录中共有 45+84=129 个政策文件条目，其中重复政策按一条记录归并，并保留其多重归属位置。根目录的政策清单说明和采购制度汇编作为补充资料附件保留。

## 本地预览

本项目是纯静态页面，可直接打开 `index.html`。如需本地服务预览，可在本目录运行：

```bash
python -m http.server 8765
```

然后访问：

```text
http://127.0.0.1:8765/
```

## 文件说明

- `index.html`：平台页面入口
- `policy-detail.html`：单项政策详情页入口
- `styles.css`：页面样式
- `app.js`：筛选、切换、渲染和交互逻辑
- `policy-detail.js`：政策详情页渲染逻辑
- `data.js`：政策结构化数据
- `analysis-data.js`：政策解读、实施流程、责任单位和图谱候选映射数据
- `files/20260819政策清单/`：政策 PDF、DOC 和清单附件下载文件

如需按 `20260819政策清单` 重新生成平台数据，可运行：

```bash
python ../scripts/build_policy_platform_20260819.py
```

## 数据来源与使用说明

政策文件来自政府官网公开资料及本地整理资料。页面中的摘要、标签、任务和流程为基于文件名与目录结构生成的候选分析，用于政策研究、内部交流和资料检索，具体政策适用以原发布机关公布的正式文本为准。

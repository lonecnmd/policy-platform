# 数字深圳投资政策导航平台

这是一个用于梳理、检索和分享“数字深圳投资政策”资料的静态网页原型。页面按资金来源和资金渠道组织政策文件，并提供政策摘要、结构化标签、相关原文摘录和附件下载。

## 内容范围

平台按照三组资金来源、八类资金渠道组织政策：

- A 政府财政资金
- B 政府债券资金
- C 其他资金

资金渠道包括中央预算内投资资金、上级财政专项资金、市本级财政投资资金、超长期特别国债及“两重”建设资金、地方政府专项债券资金、政策性金融资金、不动产投资信托基金和社会投资。

## 本地预览

本项目是纯静态页面，可直接打开 `index.html`。如需本地服务预览，可在本目录运行：

```bash
python -m http.server 8765
```

然后访问：

```text
http://127.0.0.1:8765/
```

## 文件说明

- `index.html`：平台页面入口
- `styles.css`：页面样式
- `app.js`：筛选、切换、渲染和交互逻辑
- `data.js`：政策结构化数据
- `files/`：政策 PDF 和公开附件下载文件

## 数据来源与使用说明

政策文件来自政府官网公开资料及本地整理资料。页面中的摘要、标签和原文摘录用于政策研究、内部交流和资料检索，具体政策适用以原发布机关公布的正式文本为准。

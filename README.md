# 投资政策知识平台（优化版）

这是在 `policy-platform` 基础上复制出的优化版，不覆盖原版本。页面从“文件列表”升级为“政策知识工作台”，提供资金渠道导办、去重政策清单、图谱视图、政策详情页、核心条款导读、完整原文阅读和条款定位。

## 内容范围

平台按照三组资金来源、八类资金渠道组织政策：

- A 政府财政资金
- B 政府债券资金
- C 其他资金

资金渠道包括中央预算内投资资金、上级财政专项资金、市本级财政投资资金、超长期特别国债及“两重”建设资金、地方政府专项债券资金、政策性金融资金、不动产投资信托基金和社会投资。

## 本地预览

本项目是纯静态页面，可直接打开 `index.html`。如需本地服务预览，可在本目录运行：

```bash
python -m http.server 8765
```

然后访问：

```text
http://127.0.0.1:8765/
```

## 文件说明

- `index.html`：平台页面入口
- `policy-detail.html`：单项政策详情页入口
- `styles.css`：页面样式
- `app.js`：智能导办、资金磁贴、联动筛选、收藏、图谱和清单渲染
- `policy-detail.js`：政策详情页四层信息模型、条款定位、关键词高亮和图谱渲染
- `data.js`：政策结构化数据
- `analysis-data.js`：政策解读、实施流程、责任单位和图谱候选映射数据
- `policy-text-data.js`：政策完整抽取文本，用于详情页原文阅读
- `files/`：政策 PDF 和公开附件下载文件

如需重新生成政策解读数据，可运行：

```bash
$env:TARGET_PLATFORM_DIR=(Get-Location).Path
node ../scripts/generate_policy_analysis.js
Remove-Item Env:\TARGET_PLATFORM_DIR
```

## 数据来源与使用说明

政策文件来自政府官网公开资料及本地整理资料。页面中的摘要、标签和原文摘录用于政策研究、内部交流和资料检索，具体政策适用以原发布机关公布的正式文本为准。
